# ◆ CX Profit Platform

**Аналитическая платформа клиентского опыта для крупного банка.**

Рабочее SPA-приложение с дашбордом, симулятором и аналитикой — 
не маркетинговый сайт, а прототип продукта.

## Быстрый старт

```bash
npm install
npm run dev
```

## Стек

- Vite 6 + vanilla JS
- Chart.js (интерактивные графики)
- SPA-роутинг без фреймворков

## Разделы

- **Дашборд** — CX Command Center: KPI, графики оттока/NPS, алерты
- **Profit Cockpit** — CX-метрики в деньгах, waterfall по сегментам
- **Симулятор** — Flight simulator: меняй параметры → смотри эффект на выручку
- **Voice AI** — LLM-поиск по жалобам (демо с мок-данными)
- **ROI** — Калькулятор окупаемости
