# User Stories — CX Profit Platform

## Epic 1: CX Command Center (Диспетчерская клиентского опыта)

### US-1.1: Карта потоков в реальном времени
**As a** Head of Retail  
**I want** видеть live-карту движения клиентов по точкам контакта  
**So that** я могу мгновенно заметить аномалии (например, массовый уход из ипотечного процесса)

**Acceptance criteria:**
- Карта отображает ≥100K клиентов в реальном времени
- Каждый клиент — «капля» с цветовой индикацией (зелёный = OK, жёлтый = риск, красный = отток)
- Размер капли пропорционален CLV
- Воронки по продуктам с конверсией на каждом шаге

### US-1.2: Profit-алерты
**As a** CEO  
**I want** получать push-уведомления с прогнозом финансовых потерь  
**So that** я могу приоритезировать ресурсы на основе money impact

**Acceptance criteria:**
- Каждый алерт содержит: что случилось, сколько клиентов затронуто, прогнозируемая потеря в $, предложение действия
- Возможность: Snooze, Escalate, Assign to team
- История алертов с трекингом resolution

### US-1.3: Action-кнопки
**As a** Head of CX  
**I want** нажимать кнопку «Запустить сценарий удержания» прямо из платформы  
**So that** я не теряю время на переключение между системами

**Acceptance criteria:**
- Кнопка запускает workflow (email → SMS → call) для целевой группы клиентов
- Перед запуском показывается прогноз эффекта в $
- После запуска — трекинг результатов (сколько клиентов удержано, сколько денег сохранено)

## Epic 2: Profit Cockpit (Связь CX с P&L)

### US-2.1: Profit Waterfall
**As a** CFO / CEO  
**I want** видеть waterfall-диаграмму «Потери на клиентском опыте»  
**So that** я понимаю, какие каналы и продукты теряют деньги

**Acceptance criteria:**
- Waterfall строится от идеального дохода до фактического
- Каждый блок waterfall — точка контакта или этап CJM
- Возможность drill-down до конкретной причины

### US-2.2: CX-to-Revenue отчёт
**As a** Board member  
**I want** ежемесячный отчёт «CX → Revenue Impact»  
**So that** я вижу динамику связи опыта и прибыли

**Acceptance criteria:**
- Каждый пункт NPS, CSAT, CES конвертирован в $
- Динамика за период (месяц/квартал/год)
- Baseline = что было бы без изменений (causal model)

## Epic 3: Simulation Sandbox (Что-если анализ)

### US-3.1: Flight Simulator
**As a** Product Owner розницы  
**I want** менять параметры (время ответа, количество шагов, tone of voice) и видеть эффект на выручку  
**So that** я могу обосновать изменения цифрами, а не интуицией

**Acceptance criteria:**
- ≥15 регулируемых параметров
- Результаты: конверсия, удержание, revenue, NPS
- Возможность сохранить сценарий и поделиться ссылкой

### US-3.2: Causal A/B на исторических данных
**As a** Data Scientist  
**I want** запускать causal inference модели на исторических данных  
**So that** я могу сказать: «именно это изменение *вызвало* рост на X%, а не что-то другое»

**Acceptance criteria:**
- Поддержка DoWhy / EconML
- Оценка ATE (Average Treatment Effect)
- Визуализация: Causal Graph + Sensitivity Analysis

## Epic 4: Voice-of-Customer AI

### US-4.1: Семантический поиск по жалобам
**As a** Аналитик CX  
**I want** написать «почему люди уходят после оформления кредитки» и получить топ-5 причин с цитатами  
**So that** я не переслушиваю 500 записей, а сразу вижу инсайты

**Acceptance criteria:**
- Поддержка естественного языка (LLM-powered)
- Результат: причины + цитаты + эмоциональная окраска + тяжесть (сколько клиентов)
- Фильтрация по: продукту, сегменту, каналу, времени

### US-4.2: Emotion Timeline
**As a** руководитель контакт-центра  
**I want** видеть timeline эмоций клиента на всём пути
**So that** я понимаю, где именно ломается опыт

**Acceptance criteria:**
- Timeline строится из звонков, чатов, сообщений
- Позитивные/негативные/нейтральные точки
- Correlation с последующими действиями (отток, повторный визит, жалоба)

## Epic 5: Онбординг & Интеграция

### US-5.1: Data Connect Wizard
**As a** CTO  
**I want** пошаговый коннектор к источникам (CRM, Call-центр, Core, Mobile)  
**So that** я подключаю банк за день, а не за квартал

**Acceptance criteria:**
- Готовые коннекторы к top-10 CRM (Salesforce, MS Dynamics, Oracle)
- REST API + Webhooks для кастомных систем
- Data quality dashboard: какие данные приходят, какие нет

### US-5.2: Role-based Access
**As a** CISO банка  
**I want** RBAC с аудитом и Data Masking  
**So that** я соблюдаю требования ЦБ и 152-ФЗ

## Definition of Ready
- Story содержит Acceptance Criteria
- Оценена в Story Points (1-13)
- Бизнес-ценность явно указана
- Зависимости отмечены
- Доступны тестовые данные

## Definition of Done
- Code review пройден
- Unit test покрывает Acceptance Criteria
- E2E test написан
- Документация обновлена
- QA acceptance пройден
